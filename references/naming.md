# Workshop Naming

Naming happens AFTER topic framing (you need the audience + transformation first), and gets revisited after the interview if a better named mechanism emerged from the expert's own language. Present **7–10 candidates across distinct angles** and let the expert pick or remix — never a single take-it-or-leave-it name.

## The angles (generate 1–3 per angle)

1. **Two-word punch** (the Noske pattern: "Workshop Mastery," "Lean Launch," "Funnel Builder") — [Topic] + Mastery/Builder/Engine/System, or a sharper unexpected pair. Best for curriculum lessons; ages well in a library.
2. **Hormozi MAGIC** (from $100M Offers) — stack 3–5 of: **M**agnetic reason, **A**vatar, **G**oal, **I**nterval, **C**ontainer word (Blueprint, Bootcamp, Intensive, Sprint, Lab, Workshop). E.g. "The 90-Minute Ad Machine for Coaches." Best for paid/low-ticket workshops that must sell from the title alone.
3. **Named mechanism** — brand the framework itself and let the workshop carry its name ("The Narrative Engine," "The Story Bank"). Strongest long-term IP; requires the mechanism to actually be distinct.
4. **Outcome + container** — the dream result plus a power word: "[Outcome] Blueprint/Formula/System." Clear, searchable, a little generic — good fallback.
5. **Contrarian/negation** — challenge the default belief: "Funnels Are Dead," "Stop Making Content." Best for free workshops that must grab cold traffic.
6. **Before→after** — the transformation in the title: "From Ghost Town to Booked Out."

## Rules

- **Clarity beats cleverness.** A first-time hearer should know roughly what they'll learn. Clever-but-vague loses to plain-but-specific every time.
- ≤ 65 characters (search + thumbnail friendly); the punchy angles should be ≤ 30.
- Say it out loud — the speaker has to open with "Welcome to ___" without cringing.
- Power words earn their place only if true: Proven/Complete/Secret with no proof reads as hype. Prefer the expert's own concrete language from the interview.
- Subtitle carries the specifics: short name up top, one-line promise underneath (the deck's cover `sub` field). "Ad Mastery — how to write ads people actually stop for."
- Check collisions: quick search that the name isn't a well-known competitor's product.
- Free workshop → optimize the name for curiosity + click (angles 2, 5, 6). Curriculum lesson → optimize for the library shelf (angles 1, 3).

## Format for presenting candidates

```
[Angle] — Name
   Sub: one-line promise
   Why it works: one sentence
```
